# Attachee Attendance Tracking System (AATS)

## Project Overview
The Attachee Attendance Tracking System is a web-based platform designed for organizations hosting attachees to replace manual, paper-based attendance tracking. It integrates pre-registered attachee profiles with an automated, Wi-Fi-verified check-in process.

## Key Features
* **Zero-Registration Sync:** Uses pre-existing attachee registration records to avoid duplicate registrations.
* **Hub Wi-Fi Verification:** Ensures physical presence by verifying the device's connected network before logging attendance.
* **Real-Time Supervisor Dashboard:** Allows supervisors to monitor daily attendance logs instantly.
* **Automated Reporting:** Generates quick, error-free attendance summaries for evaluation.

## Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** Supabase (PostgreSQL) / MySQL
